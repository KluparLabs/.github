# KluparLabs

Software and infrastructure for a household: the systems we run, the apps
we build on them, and the conventions that keep them honest.

- One repo per deployable package, each started from a shared template.
- One hub repo, `platform`, that maps every system and how they connect.
- One board for all work, with a ticket before every change.
- No secrets in any repo, ever. Documentation names where a secret lives.

Found a security problem? See [SECURITY.md](../SECURITY.md).
